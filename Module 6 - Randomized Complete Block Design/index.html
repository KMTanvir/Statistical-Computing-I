Welcome to Module 6

The Randomized Complete Block Design (RCBD) is the natural extension of CRD when experimental units are not homogeneous. We pull one known nuisance factor out and treat it as a block, so the F test for treatments is no longer contaminated by it.

Description of RCBD

  • Used when experimental units fall into identifiable groups (blocks) that differ in known ways: soil fertility strata, fabric batches, days of the week, time slots, machines.
  • Within each block, every treatment appears exactly once (hence "complete"). Treatments are randomly assigned within each block.
  • Each block acts as a mini CRD. The block effect absorbs systematic between block variation that would otherwise inflate the error term.

How RCBD differs from CRD

AspectCRDRCBD
Experimental unitsHomogeneousGrouped into blocks that differ
RandomisationAcross all unitsWithin each block
Model termsμ + τi + εijμ + τi + βj + εij

The Linear Model and Two Hypotheses

Fixed effects model for RCBD

yij  =  μ  +  τi  +  βj  +  εij

i = 1, ..., a treatments; j = 1, ..., b blocks; one observation per (i, j) cell

  • yij: observation under treatment i in block j.
  • μ: overall grand mean.
  • τi: effect of treatment i (deviation from μ), with constraint Σ τi = 0.
  • βj: effect of block j, with constraint Σ βj = 0.
  • εij: random error, iid Normal(0, σ2).

Two hypotheses, one ANOVA

For treatments.
H0(T): τ1 = ... = τa = 0    (no treatment effect)
H1(T): at least one τi ≠ 0

For blocks.
H0(B): β1 = ... = βb = 0    (no block effect)
H1(B): at least one βj ≠ 0
The block F test has a different role. We are usually not interested in the block effect on its own. Testing the block effect tells us whether blocking was a good idea: if the block F is large, blocking absorbed real variation and the treatment F is more powerful than a CRD would have been. If the block F is small, blocking did not help much.

Assumptions to check, same three as CRD

  1. Normality of residuals (QQ plot)
  2. Equal variance across all treatment-by-block cells (residuals vs fitted)
  3. Independence of errors (residuals vs run order)

Our Working Dataset

BARI wheat variety trial 2024, 4 varieties tested across 5 soil fertility blocks.

BARI tested four wheat varieties (BARI Gom 24, 26, 30, 33) on five soil fertility strata (Block 1 lowest, Block 5 highest). Each variety appears exactly once in each block, giving 4 × 5 = 20 observations. The response is grain yield (Mg/ha).

Type the data into R

# 4 varieties (treatments) x 5 fertility blocks, yield in Mg/ha
treat <- rep(c("V1", "V2", "V3", "V4"), times = 5)
block <- rep(c("B1", "B2", "B3", "B4", "B5"), each = 4)
yield <- c(3.30, 3.95, 4.25, 3.80,    # B1
            3.85, 4.10, 4.80, 3.95,    # B2
            4.20, 4.80, 4.95, 4.30,    # B3
            4.35, 5.05, 5.40, 4.60,    # B4
            4.90, 5.00, 5.60, 4.85)    # B5

wheat <- data.frame(treat = factor(treat),
                    block = factor(block),
                    yield)

Manual ANOVA Decomposition

With a = 4 treatments and b = 5 blocks, N = a × b = 20. The total variation now splits into three pieces: treatments, blocks, and error.

CF  =  G2 / N
SStotal  =  Σ y2  −  CF
SStreat  =  Σ Ti2 / b  −  CF
SSblock  =  Σ Bj2 / a  −  CF
SSerror  =  SStotal  −  SStreat  −  SSblock

Degrees of freedom

  • dftreat = a − 1 = 3
  • dfblock = b − 1 = 4
  • dferror = (a − 1)(b − 1) = 12
  • dftotal = N − 1 = 19   (and 3 + 4 + 12 = 19 ✓)

Compute it in R

a <- 4; b <- 5; N <- a * b

CF       <- sum(wheat$yield)^2 / N
SST      <- sum(wheat$yield^2) - CF

T_tot    <- tapply(wheat$yield, wheat$treat, sum)
B_tot    <- tapply(wheat$yield, wheat$block, sum)

SS_treat <- sum(T_tot^2) / b - CF
SS_block <- sum(B_tot^2) / a - CF
SSE      <- SST - SS_treat - SS_block

df_treat <- a - 1
df_block <- b - 1
df_error <- (a - 1) * (b - 1)

MS_treat <- SS_treat / df_treat
MS_block <- SS_block / df_block
MSE      <- SSE      / df_error

F_treat  <- MS_treat / MSE
F_block  <- MS_block / MSE

c(SS_treat = SS_treat, SS_block = SS_block, SSE = SSE,
        F_treat = F_treat, F_block = F_block)
#> SS_treat SS_block      SSE  F_treat  F_block 
#>    2.204    4.131    0.245   35.967   50.580

Ftab at α = 0.05 are qf(0.95, 3, 12) = 3.49 for treatments and qf(0.95, 4, 12) = 3.26 for blocks. Both calculated F values are far larger, so we reject both nulls.

One Line ANOVA with aov()

The whole RCBD analysis collapses to one model fit, with treatment and block on the right hand side of the formula.

model <- aov(yield ~ treat + block, data = wheat)

#> Residuals   12  0.245  0.0204

Was blocking worthwhile?

Yes, by a wide margin. If we had run this as a CRD (no block term), the block SS would have been pooled into the error, giving MSE ≈ (0.245 + 4.131) / (12 + 4) = 0.274 instead of 0.020. The treatment F would have dropped from 35.97 down to roughly 2.68, around the borderline at α = 0.05. Blocking on soil fertility roughly 14× the precision of the treatment test here.

Conclusions. Both treatments and blocks are highly significant. Variety has a real effect on yield, and the soil fertility strata also vary systematically. We will identify which varieties differ in Slide 8 with Tukey HSD.

Estimating Treatment and Block Effects

The ANOVA tells us treatments differ. To say by how much, we estimate each effect as a deviation from the grand mean.

μ  =  ȳ.. (grand mean)
τi  =  ȳi.  −  ȳ..  (treatment effect)
βj  =  ȳ.j  −  ȳ..  (block effect)

Compute it in R

grand_mean <- mean(wheat$yield)                  # 4.50
treat_mean <- tapply(wheat$yield, wheat$treat, mean)
block_mean <- tapply(wheat$yield, wheat$block, mean)

tau_hat  <- treat_mean - grand_mean
beta_hat <- block_mean - grand_mean

cbind(mean = treat_mean, tau_hat = tau_hat)
#>    mean tau_hat
#> V1 4.12   -0.38
#> V2 4.58    0.08
#> V3 5.00    0.50
#> V4 4.30   -0.20

cbind(mean = block_mean, beta_hat = beta_hat)
#>    mean beta_hat
#> B1 3.825    -0.675
#> B2 4.175    -0.325
#> B3 4.5625    0.0625
#> B4 4.85      0.35
#> B5 5.0875    0.5875
How to read it. V3 boosts yield by 0.50 Mg/ha above the grand mean, V1 drops it by 0.38. Block 5 (high fertility) adds 0.59 to any variety planted there, Block 1 (low fertility) subtracts 0.68. The two effects add to give the cell mean exactly under the fitted model.

Sum of estimates equals zero, by construction

sum(tau_hat)
#> [1] 0
sum(beta_hat)
#> [1] 0

Model Adequacy Checks

The three standard checks from CRD carry over unchanged. Extract residuals from the fitted model and inspect three plots.

res <- residuals(model)
fit <- fitted(model)

# 1. Normality of residuals
qqnorm(res, pch = 19, col = "#2563eb",
       main = "Normal QQ plot of residuals")
qqline(res, col = "#dc2626", lwd = 2)

# 2. Equal variance across fitted values
plot(fit, res, pch = 19, col = "#2563eb",
     xlab = "Fitted values", ylab = "Residuals",
     main = "Residuals vs Fitted")
abline(h = 0, lty = 2, col = "#dc2626")

# 3. Independence, residuals vs run order
plot(seq_along(res), res, type = "b", pch = 19, col = "#2563eb",
     xlab = "Run order", ylab = "Residuals",
     main = "Residuals vs run order")
abline(h = 0, lty = 2, col = "#dc2626")
What to look for, briefly. A QQ plot with points hugging the line supports normality. A flat horizontal band on the residuals vs fitted plot supports equal variance. Random scatter on the run order plot supports independence. Patterns or trends in any plot threaten the F test conclusions.
Shortcut. plot(model) draws four standard diagnostic panels in one call (residuals vs fitted, QQ plot, scale location, leverage).

Pairwise Comparison and When Blocking Helps

Tukey HSD on the treatment factor only

Even when the model has a block term, we only want pairwise comparisons among treatments. Pass the treatment factor explicitly to TukeyHSD():

TukeyHSD(model, "treat", conf.level = 0.95)
#> $treat
#>        diff     lwr    upr   p adj
#> V2-V1  0.46  0.1925 0.7275 0.0011
#> V3-V1  0.88  0.6125 1.1475 0.0000
#> V4-V1  0.18 -0.0875 0.4475 0.2331
#> V3-V2  0.42  0.1525 0.6875 0.0023
#> V4-V2 -0.28 -0.5475 -0.0125 0.0391
#> V4-V3 -0.70 -0.9675 -0.4325 0.0000

Reading the output

  • V3 vs V1, V3 vs V2, V3 vs V4: V3 (BARI Gom 30) is significantly higher than every other variety.
  • V2 vs V1: V2 is significantly higher than V1.
  • V4 vs V2: V4 sits just below V2 (p = 0.04).
  • V4 vs V1: not significantly different at 5% (p = 0.23).

Was blocking worthwhile? A formal check

If the block F is large and its p value small, blocking captured real systematic variation. In our trial, the block F is 50.58 with p < 0.001, so blocking was clearly justified.

Decision rule of thumb. If Fblock > 1 and small relative to Ftab, blocking did not hurt but did not help much. If Fblock is much larger than Ftab, blocking sharply increased the precision of the treatment test. If Fblock is below 1, the block structure might even have wasted degrees of freedom; in retrospect a CRD might have been cleaner.
