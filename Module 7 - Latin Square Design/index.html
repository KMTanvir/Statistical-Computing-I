Welcome to Module 7

The Latin Square Design (LSD) extends RCBD by blocking out two nuisance factors at once. The result is a square layout in which each treatment appears exactly once in each row and exactly once in each column.

When to use a Latin Square

  • You have a single factor with p levels (the treatments) whose effect you want to estimate.
  • You can identify two known sources of variability beyond the treatment itself: a row factor and a column factor.
  • You can lay out the experiment in a p × p grid so that each treatment appears once per row and once per column.

Why bother

RCBD removes one nuisance factor from the error term. LSD removes two. If both nuisance factors really matter, this further sharpens the F test for treatments. The trade off is that LSD requires the number of treatments to equal the number of rows and the number of columns.

What you will be able to do by the end of this lab

  • Recognise when a Latin Square is more appropriate than an RCBD
  • Construct a p × p Latin Square and randomise it correctly
  • Write the LSD linear model and the three F tests it supports
  • Compute the full ANOVA table by hand with four sources of variation
  • Fit the same model with aov(y ~ treat + row + column, data = df)
  • Estimate treatment effects and run pairwise comparisons with Tukey HSD

Constructing a Latin Square

Every treatment exactly once per row and exactly once per column.

Row 2BCDA
Row 3CDAB
Row 4DABC

Randomisation procedure, three steps

Just like RCBD, the Latin Square has restricted randomisation: we cannot assign treatments freely because the row and column constraints must hold. The standard recipe is:

  1. Randomly select a generating design from the set of standard p × p Latin Squares.
  2. Randomly permute the p columns.
  3. Randomly permute the last p − 1 rows (leaving the first row fixed).

Then assign the treatment letters A, B, C, ... to the actual experimental treatments at random.

# Quick R sketch of the randomisation idea for a 4x4 LSD
set.seed(232)

base <- matrix(c("A","B","C","D",
                 "B","C","D","A",
                 "C","D","A","B",
                 "D","A","B","C"),
               nrow = 4, byrow = TRUE)

col_perm <- sample(1:4)                    # permute columns
row_perm <- c(1, 1 + sample(1:3))         # first row fixed
square <- base[row_perm, col_perm]
square
Real example. An agronomist runs four tea varieties in a Sylhet plantation. The slope (rows) and the prevailing wind direction (columns) both affect yield. A 4 × 4 Latin Square gives each variety one plot at each slope position and one plot at each wind exposure, so neither nuisance factor confounds the variety comparison.

The Linear Model and Three F Tests

Fixed effects model for LSD

yijk  =  μ  +  αi  +  βj  +  τk  +  εijk

i = 1, ..., p rows; j = 1, ..., p columns; k = 1, ..., p treatments. Exactly one observation per (i, j) cell.

  • μ: overall grand mean.
  • αi: row effect (first nuisance factor).
  • βj: column effect (second nuisance factor).
  • τk: treatment effect (the question of interest).
  • εijk: random error, iid Normal(0, σ2).

Three null hypotheses

For treatments: H0(T): all τk = 0   (the question of interest)
For rows: H0(R): all αi = 0   (blocking check)
For columns: H0(C): all βj = 0   (blocking check)

Degrees of freedom budget

  • dfrow = p − 1
  • dfcol = p − 1
  • dftreat = p − 1
  • dferror = (p − 1)(p − 2)
  • dftotal = N − 1 = p2 − 1

For p = 4: df_row = 3, df_col = 3, df_treat = 3, df_error = 6, df_total = 15. Sum check: 3 + 3 + 3 + 6 = 15 ✓

Small p means small error df. A 3 × 3 Latin Square has only df_error = 2, too few for a reliable F test. A 4 × 4 has df_error = 6, the practical minimum. For p ≥ 5 the error term has comfortable degrees of freedom.

Manual ANOVA Decomposition

With p = 4, N = p2 = 16. Total variation splits into four pieces: rows, columns, treatments, and error.

CF  =  G2 / N
SStotal  =  Σ y2  −  CF
SSrow  =  Σ Ri2 / p  −  CF
SScol  =  Σ Cj2 / p  −  CF
SStreat  =  Σ Tk2 / p  −  CF
SSerror  =  SStotal  −  SSrow  −  SScol  −  SStreat

Compute it in R

p <- 4; N <- p^2

CF       <- sum(tea$yield)^2 / N
SST      <- sum(tea$yield^2) - CF

R_tot    <- tapply(tea$yield, tea$row,    sum)
C_tot    <- tapply(tea$yield, tea$column, sum)
T_tot    <- tapply(tea$yield, tea$trt,    sum)

SS_row   <- sum(R_tot^2) / p - CF
SS_col   <- sum(C_tot^2) / p - CF
SS_treat <- sum(T_tot^2) / p - CF
SSE      <- SST - SS_row - SS_col - SS_treat

df_each  <- p - 1            # 3 for row, col, treat
df_error <- (p - 1) * (p - 2)  # 6

MS_row   <- SS_row   / df_each
MS_col   <- SS_col   / df_each
MS_treat <- SS_treat / df_each
MSE      <- SSE      / df_error

F_row    <- MS_row   / MSE
F_col    <- MS_col   / MSE
F_treat  <- MS_treat / MSE

c(SS_row = SS_row, SS_col = SS_col,
        SS_treat = SS_treat, SSE = SSE,
        F_row = F_row, F_col = F_col, F_treat = F_treat)
#> SS_row  SS_col SS_treat   SSE  F_row  F_col F_treat 
#>  1.423   0.628    2.140 0.101  28.15  12.42   42.35

Ftab at α = 0.05 is qf(0.95, 3, 6) = 4.757 for all three tests. All three calculated F values exceed it, so all three nulls are rejected.

How to read it. Variety has a clear effect on yield (F = 42.4, p < 0.001). Both nuisance factors are also significant: slope (F = 28.2) and wind exposure (F = 12.4). All three blocking checks confirm the Latin Square layout was the right choice for this experiment.

Was the Latin Square worth it?

If we had ignored both blocking factors and run this as a CRD, the row and column sums of squares (1.423 + 0.628 = 2.051) would have been pooled into the error. The treatment F would have dropped from 42.4 to roughly 4.4, near the borderline. Blocking on both slope and wind exposure roughly 10× the precision of the variety test.

Effect Estimates and Model Adequacy

Estimated effects

Each effect is the corresponding sample mean minus the grand mean.

grand_mean <- mean(tea$yield)                  # 4.997
treat_mean <- tapply(tea$yield, tea$trt,    mean)
row_mean   <- tapply(tea$yield, tea$row,    mean)
col_mean   <- tapply(tea$yield, tea$column, mean)

tau_hat   <- treat_mean - grand_mean
alpha_hat <- row_mean   - grand_mean
beta_hat  <- col_mean   - grand_mean

cbind(treat_mean, tau_hat)
#>   treat_mean tau_hat
#> A      4.675  -0.322
#> B      5.150   0.153
#> C      5.525   0.528
#> D      4.638  -0.359
Reading the treatment effects. Variety C is the best at +0.53 above the grand mean, followed by B at +0.15. A and D both sit roughly 0.3 below the grand mean. Row effects (slope) grow steadily from Row 1 to Row 4. Column effects show that the windward column (Col 1) is the worst, with the leeward side better.

Model adequacy, the same three checks

res <- residuals(model)
fit <- fitted(model)

qqnorm(res, pch = 19, col = "#2563eb")
qqline(res, col = "#dc2626", lwd = 2)

plot(fit, res, pch = 19, col = "#2563eb",
     xlab = "Fitted", ylab = "Residuals")
abline(h = 0, lty = 2, col = "#dc2626")

plot(seq_along(res), res, type = "b", pch = 19, col = "#2563eb",
     xlab = "Run order", ylab = "Residuals")
abline(h = 0, lty = 2, col = "#dc2626")
Small p, small df_error. With only 6 error degrees of freedom in a 4 × 4 square, diagnostic plots are noisy. A QQ plot with 16 points cannot tell us much about the tails. Treat the assumption checks as a sanity pass, not a definitive test, when p is small.

Pairwise Comparison with Tukey HSD

Just like in CRD and RCBD, the F test for treatments tells us at least one variety differs. Tukey HSD identifies which pairs differ, while controlling the family wise error rate.

TukeyHSD(model, "trt", conf.level = 0.95)
#> $trt
#>        diff      lwr      upr   p adj
#> B-A   0.475  0.0395  0.9105 0.0338
#> C-A   0.850  0.4145  1.2855 0.0019
#> D-A  -0.038 -0.4730  0.3980 0.9929
#> C-B   0.375 -0.0605  0.8105 0.0900
#> D-B  -0.513 -0.9480 -0.0770 0.0247
#> D-C  -0.888 -1.3230 -0.4520 0.0015

Reading the table

  • C vs A and C vs D: C wins by a clear margin, both significant.
  • B vs A and D vs B: significant at the 5% family wise level (just).
  • C vs B: borderline (p = 0.09), not significant at 5% but close.
  • D vs A: essentially identical (p = 0.99).
