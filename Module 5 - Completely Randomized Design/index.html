Welcome to Module 5

The Completely Randomized Design (CRD) is the simplest experimental design and the foundation for everything that follows in Block 2. We will work through one full CRD analysis in R, from raw data to confidence intervals.

Description of CRD

  • The simplest design to use. Treatments are assigned to experimental units completely at random.
  • Used when experimental units are essentially homogeneous, no obvious nuisance factor.
  • Because of the homogeneity requirement, it can be difficult to use for field experiments where soil, weather, or location vary.
  • Best suited to experiments with a small number of treatments and a moderate number of replicates per treatment.

What you will be able to do by the end of this lab

  • State the linear additive model for CRD and the hypothesis test of interest
  • Compute the ANOVA table manually (SS, df, MS, F) on a small dataset
  • Run the same analysis in one line with aov() and summary()
  • Check model adequacy with normality, equal variance, and independence plots
  • Build one at a time and Bonferroni simultaneous confidence intervals for treatment means
  • Perform pairwise comparisons with Tukey's Honest Significant Difference (HSD) test

The Linear Additive Model and the Hypothesis

Fixed effects model for CRD

Each observation is the sum of an overall mean, a treatment effect, and a random error.

yij  =  μ  +  τi  +  εij

i = 1, ..., a treatments; j = 1, ..., n replicates per treatment

  • yij is the jth observation under the ith treatment.
  • μ is the overall mean across the whole experiment.
  • τi is the effect of the ith treatment, measured as deviation from the overall mean.
  • εij is the random error, assumed iid Normal with mean 0 and variance σ2.

The hypothesis we test

H0: τ1 = τ2 = ... = τa = 0    (all treatments have the same mean)

H1: at least one τi ≠ 0    (at least one treatment mean is different)

Assumptions, the three we will check

  1. Normality of errors. Checked with a QQ plot of residuals.
  2. Equal variance across treatments (homoscedasticity). Checked with a residuals vs fitted plot.
  3. Independence of errors. Checked by plotting residuals against time or run order.
Why these three? The F test in ANOVA assumes the errors are independent draws from a single Normal distribution. If any of the three is grossly violated, the F statistic does not follow its theoretical distribution and the p value is unreliable.

Our Working Dataset

BARI rice fertilizer trial 2024, 4 treatments and 5 replicate plots each.

The Bangladesh Agricultural Research Institute (BARI) ran a CRD trial comparing four fertilizer regimes on rice yield (Mg per hectare). Twenty homogeneous plots were assigned at random, five per fertilizer. Treatments are Urea, NPK, Compost, and Mixed (NPK + compost).

Type the data into R

# Four fertilizer treatments, five replicates each
treat <- rep(c("Urea", "NPK", "Compost", "Mixed"), each = 5)
yield <- c(4.2, 4.8, 4.0, 4.5, 4.4,    # Urea
            5.3, 4.7, 5.1, 5.5, 4.9,    # NPK
            4.1, 3.8, 4.3, 3.9, 4.2,    # Compost
            5.4, 5.9, 5.3, 5.7, 5.6)    # Mixed

rice <- data.frame(treat = factor(treat), yield)

tapply(rice$yield, rice$treat, mean)
#> Compost   Mixed     NPK    Urea 
#>    4.06    5.58    5.10    4.38

Eyeball it with a boxplot

boxplot(yield ~ treat, data = rice,
        col = "#dbeafe", border = "#2563eb",
        xlab = "Fertilizer", ylab = "Rice yield (Mg/ha)",
        main = "BARI Rice Trial 2024")

What the boxplot looks like

What the boxplot suggests. The Mixed and NPK treatments visibly produce higher yields than Urea and Compost. The four boxes barely overlap. This is what we want to see before running the F test, a clear visual signal that treatment matters. The ANOVA will quantify that signal formally.

Manual ANOVA Decomposition

Before we hand it to aov(), let's walk through the calculation by hand to build intuition for what the F statistic measures.

Notation and totals

Let a = 4 treatments and n = 5 replicates per treatment, so N = a × n = 20 total observations. Let Ti be the sum for treatment i and G the grand total.

TreatmentTi (sum)Mean
Urea21.94.38
NPK25.55.10
Compost20.34.06
Mixed27.95.58
GrandG = 95.6ȳ = 4.78

Sums of squares

CF  =  G2 / N
SStotal  =  Σ y2  −  CF
SStreat  =  Σ Ti2 / n  −  CF
SSerror  =  SStotal  −  SStreat

Compute it in R, step by step

a <- 4;  n <- 5;  N <- a * n

CF <- sum(rice$yield)^2 / N
SST <- sum(rice$yield^2) - CF

treat_sum <- tapply(rice$yield, rice$treat, sum)
SS_treat <- sum(treat_sum^2) / n - CF
SSE <- SST - SS_treat

df_treat <- a - 1          # 3
df_error <- N - a          # 16

MS_treat <- SS_treat / df_treat
MSE      <- SSE      / df_error
F_calc   <- MS_treat / MSE
F_tab    <- qf(0.95, df_treat, df_error)

c(SS_treat = SS_treat, SSE = SSE,
        MS_treat = MS_treat, MSE = MSE,
        F_calc = F_calc, F_tab = F_tab)
#>  SS_treat       SSE  MS_treat       MSE    F_calc     F_tab 
#>     7.104     1.168     2.368     0.073    32.438     3.239
The decision. Fcalc = 32.44 is far larger than Ftab = 3.24 at α = 0.05. Reject H0. At least one fertilizer treatment produces a different mean yield from the others.

Model Adequacy Checks

The F test result is only as good as the assumptions. Three diagnostic plots cover normality, equal variance, and independence.

Compute residuals and fitted values

res <- residuals(model)
fit <- fitted(model)

1. Normality, QQ plot of residuals

qqnorm(res, pch = 19, col = "#2563eb",
       main = "Normal QQ plot of residuals")
qqline(res, col = "#dc2626", lwd = 2)

Look for points scattering close to the diagonal reference line, especially through the middle of the plot. Mild curvature at the tails is usually acceptable.

2. Equal variance, residuals vs fitted

plot(fit, res, pch = 19, col = "#2563eb",
     xlab = "Fitted values", ylab = "Residuals",
     main = "Residuals vs Fitted")
abline(h = 0, lty = 2, col = "#dc2626")

You want a horizontal band of points with no obvious pattern. A funnel shape, where spread grows with the fitted value, suggests unequal variances and may need a transformation of the response.

3. Independence, residuals in run order

plot(seq_along(res), res, type = "b", pch = 19, col = "#2563eb",
     xlab = "Run order", ylab = "Residuals",
     main = "Residuals vs run order")
abline(h = 0, lty = 2, col = "#dc2626")

If residuals show runs of positives followed by runs of negatives, time order is correlated with the outcome. In a properly randomised CRD this should not happen, but it is worth checking.

Shortcut. plot(model) draws four standard diagnostic panels in one call (residuals vs fitted, QQ plot, scale location, leverage). Press Return in the console between panels.

Confidence Intervals for Treatment Means

An F test tells us treatments differ. Confidence intervals tell us how much, and with what precision.

One at a time confidence interval

ȳi.  ±  tα/2, N−a  ×  √(MSE / n)

This is the standard 95% CI for a single treatment mean. The standard error is √(MSE / n), and the multiplier is the t critical value with N − a error degrees of freedom.

# 95% one at a time CI for the NPK mean
y_npk <- mean(rice$yield[rice$treat == "NPK"])     # 5.10
se    <- sqrt(MSE / n)                              # 0.1208
tcrit <- qt(0.975, df_error)                       # 2.1199

c(lower = y_npk - tcrit * se,
  upper = y_npk + tcrit * se)
#>    lower    upper 
#> 4.84398  5.35602

Bonferroni simultaneous confidence intervals

When we build r intervals at the same time, the probability that all of them simultaneously contain their true means is no longer 1 − α. The Bonferroni correction divides α by r, ensuring the overall confidence level is at least 1 − α.

Bonferroni multiplier:   tα/(2r), N−a 
# 95% Bonferroni simultaneous CIs for all 4 treatment means
r <- a                                            # number of intervals
tcrit_bonf <- qt(1 - 0.05 / (2 * r), df_error)  # 2.8127
means <- tapply(rice$yield, rice$treat, mean)

bonf_ci <- data.frame(
  treat = names(means),
  mean  = means,
  lower = means - tcrit_bonf * se,
  upper = means + tcrit_bonf * se
)
bonf_ci
#>          treat mean lower upper
#> Compost Compost 4.06 3.720 4.400
#> Mixed     Mixed 5.58 5.240 5.920
#> NPK         NPK 5.10 4.760 5.440
#> Urea       Urea 4.38 4.040 4.720
How to read the Bonferroni CIs. All four 95% intervals jointly cover their true means with probability at least 0.95. The Compost and Mixed intervals do not overlap, evidence that those two means really differ. Compare the Urea and Compost intervals: they overlap, so we cannot be confident that those two means differ.

Pairwise Comparison with Tukey HSD

The F test says "at least one mean differs". To say which pairs differ, we need a multiple comparison procedure. Tukey's Honest Significant Difference (HSD) test is the standard choice for CRD with equal sample sizes.

HSD  =  qα, a, N−a  ×  √(MSE / n)

Two treatment means are declared significantly different if the absolute difference between their sample means exceeds HSD. The multiplier q is the studentised range, looked up at level α with a groups and N − a error degrees of freedom.

One line in R

TukeyHSD(model, conf.level = 0.95)
#>   Tukey multiple comparisons of means
#>     95% family-wise confidence level
#>
#> $treat
#>                  diff      lwr      upr    p adj
#> Mixed-Compost    1.52   1.0290   2.0110   0.0000
#> NPK-Compost      1.04   0.5490   1.5310   0.0001
#> Urea-Compost     0.32  -0.1710   0.8110   0.2710
#> NPK-Mixed       -0.48  -0.9710   0.0110   0.0566
#> Urea-Mixed      -1.20  -1.6910  -0.7090   0.0000
#> Urea-NPK        -0.72  -1.2110  -0.2290   0.0034

Reading the output

  • diff: difference in sample means, the second group minus the first.
  • lwr and upr: 95% family wise CI for the true difference.
  • p adj: Tukey adjusted p value. If < 0.05, the pair is significantly different at the 5% family wise level.

Practical takeaway. Mixed and NPK both clearly outperform Compost and Urea. The difference between Mixed and NPK is not quite significant at 5% (p = 0.057). For the next planting season, BARI could recommend either Mixed or NPK with confidence, and avoid Compost.
